Interfaces disponíveis

Calculadora — Regime Geral

Cálculo de CBS, IBS e Imposto Seletivo nas operações do regime geral, com observabilidade item a item e memória de cálculo.

Calculadora — Simples Nacional

Cálculo de CBS e IBS para contribuintes do Simples Nacional, com consulta de atividades por anexo e vigência.

Base de Cálculo Unificada

Composição das bases (regime geral, IS e Simples Nacional) respeitando a vigência dos componentes por ano.

Dados Abertos

NCM, NBS, classificações tributárias, comunidades legais e alíquotas de referência (União, UF e município).

Emissor DANFSe

Geração do DANFSe em PDF a partir do XML de uma NFS-e nacional, com opção de canhoto e situação da nota.

Repositórios integrados

  • calculadora-rtc-regime-regular — API Java/Spring (CBS, IBS e IS, regime geral)
  • calculadora-rtc-simples-nacional — API Java/Spring (CBS e IBS, Simples Nacional)
  • calculadora-rtc-gerador-danfse — Serviço Go de geração de DANFSe em PDF

Calculadora — Regime Geral (CBS · IBS · IS)

Opera pelo gateway (POST /api/calculo/regime-geral). No modo observabilidade, cada item é calculado mesmo que outros falhem; no modo estrito, a operação inteira falha no primeiro erro (HTTP 422).

Calculadora — Simples Nacional (CBS · IBS)

Opera pelo gateway (POST /api/calculo/simples-nacional) com observabilidade por item.

Atividades do Simples Nacional

Base de Cálculo Unificada (NF-e/NFC-e e NFS-e)

Calcula as bases regime geral, IS e Simples Nacional pela vigência dos componentes no ano do fato gerador (POST /api/calculo/base-unificada).

Dados Abertos

Consulta direta às bases oficiais usadas pelas calculadoras (GET /api/dados-abertos/…).

Emissor de DANFSe (PDF)

Envia o XML bruto de uma NFS-e nacional (POST /api/danfse) e recebe o DANFSe em PDF.

API do Gateway

Todas as chamadas abaixo são servidas pelo gateway da plataforma, que encaminha às APIs oficiais.

MétodoEndpointDescrição
GET/api/healthStatus agregado dos três serviços
POST/api/calculoCálculo unificado — campo regime: regime-geral ou simples-nacional
POST/api/calculo/regime-geral?modo=observabilidade|estritoCálculo CBS/IBS/IS do regime geral
POST/api/calculo/simples-nacionalCálculo CBS/IBS do Simples Nacional
POST/api/calculo/base-unificada?tipo=nfe|nfseBase de cálculo unificada NF-e/NFC-e ou NFS-e
GET/api/calculo/erros?codigo=REG-011|VSN-001Descrição de código de erro dos dois regimes
GET/api/simples/atividades?data=AAAA-MM-DDAtividades do Simples Nacional vigentes
GET/api/simples/atividades/{codigo}?data=AAAA-MM-DDAtividade específica do Simples

GET/api/dados-abertos/ncm · nbs · situacoes-tributarias/cbs-ibs · classificacoes-tributarias/cbs-ibs/class-trib/{codigo} · fundamentacoes-legais · aliquota-uniao · aliquota-uf · aliquota-municipioDados abertos oficiais

ANY/api/upstream/{regime|simples|danfse}/…Passagem direta parametrizada a qualquer caminho de um serviço integrado
